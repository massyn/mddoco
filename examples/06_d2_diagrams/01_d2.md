# D2 Diagrams

Render this folder with:

```bash
mddoco examples/06_d2_diagrams --title "D2 Diagrams" --output ./out
```

Fenced ` ```d2 ` blocks are rendered at build time by the
[`d2`](https://d2lang.com/tour/install) command-line tool and embedded in the
document as inline SVG, so the output needs no scripts and works offline. The
`d2` tool must be installed and on your `PATH`; documents without D2 blocks do
not need it.

## Pipeline

```d2
direction: right
files: Markdown files
convert: Convert each file
output: {
  html: HTML document
  pdf: PDF document
}
files -> convert
convert -> output.html
convert -> output.pdf: "via Playwright"
```

## Shapes and containers

```d2
direction: right
client: Client {shape: person}
server: Server {
  api: API
  db: Database {shape: cylinder}
  api -> db
}
client -> server.api: request
```
